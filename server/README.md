# AI 服务接入边界

`recommendations.mjs` 是服务端 Chat Completions 适配器，不是已部署服务。供应商待用户选择。没有真实密钥，不执行付费调用。

部署适配层必须提供 `authorize(request)`（通过可信认证服务验证身份，不相信客户端 uid）与 `reserveQuota(identity)`（持久化、原子额度控制）。缺少任一项时接口关闭，返回503。不要用恒真函数上线。

服务器环境配置：完整 HTTPS Chat Completions 地址、API key、模型。客户端不能提交服务地址或平台密钥。前端 `ai-config.js` 只放同源代理路径和服务商/模型公开名称。Cloudflare Pages 控制台的静态 ZIP 上传不会自动部署这里的 Node 模块。

前端请求只包含明确允许使用的近期记录和当下意图；不发送账号、整本日记或 API 密钥。生成结果默认只在当前页面内存保留，用户保存后以 tasks 快照同步。撤回授权或删除记录不会撤回已发给服务商的历史请求；不维护长期AI画像。

接入顺序：确定服务商 → 配置服务端密钥 → 实现认证和持久化额度适配 → 配置同源路径 → 告知前端真实服务方 → 实测授权/费用/异常 → 发布。当前仅离线模拟测试，不代表真实供应商验收。
